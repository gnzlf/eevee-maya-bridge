Instalador con actualizaciones desde GitHub y ejecución directa desde el botón de Maya.

- Instalador por usuario para Windows x64 y Maya 2024.
- Detección de Blender 5.2 y descarga portátil oficial cuando hace falta, con SHA-256 verificado.
- Menú de nuevas versiones en Maya, descarga verificada e instalación automática desde «Descargar e instalar», en carpetas independientes para el próximo inicio.
- Configuración conservada entre versiones y desinstalación desde Windows.
- Incluye las correcciones de cono/penumbra, DOF con cámaras escaladas, volumen, light linking y Ambient Color/Incandescence.

El viewport continúa siendo experimental. Requiere Maya 2024 instalado; no garantiza 30 FPS ni paridad completa con Arnold. El instalador no tiene firma de código.
